# Personal Portfolio - Zainab Muneer

**Oasis Infobyte Internship (OIBSIP)** | Track: Web Development and Designing | Task 2 (Level 2)

A responsive personal portfolio website that presents my profile, skills, projects and contact details.

## Tech stack
- HTML5
- CSS3 (Flexbox and Grid)
- Google Fonts (Poppins)
- No JavaScript

## Features
- Hero section with name, role title and an avatar placeholder
- About Me section
- Skills grid with eight technical skills
- Three project cards with GitHub links
- Contact section with email, GitHub and LinkedIn
- Smooth scrolling between sections
- One colour scheme and font family throughout
- Responsive layout for desktop, tablet and mobile

## Project structure

## How to run
1. Download or clone this repository.
2. Open the `WebDev-L2-PersonalPortfolio` folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**, or double-click `index.html` to open it in a browser.
